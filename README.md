# signoff (working name)

**Question:** when agents write most of the code, where should a product manager keep control, and does that control hold up?

This repo will hold a small tool that reads a GitHub repo, explains each change in plain language, flags the product decisions an agent made, and lets a PM choose which kinds of change need their sign-off. It also holds the measurements: how many important changes a PM catches, how many approvals the tool asks for, and how often a summary misleads.

Status: Phase 1 (data and decision types). Nothing here is ready to use yet.
